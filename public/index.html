Node.js 26 TypeScript Starter

A minimal web application on Node.js 26 LTS and TypeScript 7. One-click deploy on Railway, fast deploys from the official Node image.

It serves this page, plus a small JSON API:

  • GET /health — service health and uptime
  • GET /echo?message=hi — echoes the message parameter back

Edit public/index.html to make this page yours, and add routes in src/index.ts.
